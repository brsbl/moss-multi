# moss-multi

Multiplayer Moss: the real Moss editor UI ported to the web on glyphdown's backend architecture (Cloudflare Workers, one Durable Object per doc, D1, R2), with the Lexical tree as the document of record via the official `@lexical/yjs`.

This is a reference build for migrating Moss to multiplayer. It is a from-scratch restart of brsbl/moss-collab.
